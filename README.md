# Progetto-Sito-Web-Ospedale-
Il progetto è un sito in PHP e MySQL che collega l'Area Medica e la Farmacia di un ospedale. I medici gestiscono pazienti e prescrizioni, mentre i farmacisti controllano il magazzino. Il Front-End usa un solo CSS con layout a schede e tabelle chiare. I form hanno blocchi HTML5 per evitare errori e JavaScript mostra i campi in base al ruolo.
